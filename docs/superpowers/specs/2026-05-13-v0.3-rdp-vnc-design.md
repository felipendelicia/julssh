# julssh v0.3 — RDP/VNC Design Spec

**Date:** 2026-05-13
**Status:** Approved

## Overview

Agregar soporte para conexiones RDP y VNC con la misma UX que SSH: CRUD, lista navegable, filtro, tags. La diferencia técnica clave es que RDP/VNC abren ventanas GUI en background — el TUI sigue corriendo.

---

## Data Model

Dos campos nuevos en `Connection` (backward-compatible: `type` vacío → `"ssh"`):

```go
Type   string `json:"type"`   // "ssh" | "rdp" | "vnc"
Domain string `json:"domain"` // RDP only (Active Directory)
```

---

## Protocol Packages

### `internal/rdp/connect.go`

Lanza `xfreerdp` en background con `exec.Command.Start()`. TUI no se suspende.

```go
type MsgRDPLaunched struct{ Err error }

func Connect(c store.Connection) tea.Cmd
```

Args de xfreerdp: `/v:host:port /u:user /d:domain /dynamic-resolution`
- Puerto default: 3389 si `c.Port == 0`

### `internal/vnc/connect.go`

Lanza `vncviewer` en background.

```go
type MsgVNCLaunched struct{ Err error }

func Connect(c store.Connection) tea.Cmd
```

Arg: `host:port` — Puerto default: 5900 si `c.Port == 0`

---

## Store Changes

- Agregar `Type`, `Domain` a `Connection`
- `Load`: si `Type == ""` → `"ssh"` (migración automática, sin romper JSON existente)
- `matchesQuery`: incluir `Type` y `Domain` en búsqueda

---

## Form Changes (`model/form.go`)

Nuevo campo en enum: `fieldDomain` (entre IdentityFile y Description).

Type selector: widget propio (no textinput) con estado `typeIdx int` y `onTypeSelector bool`.
- Space/←/→ cicla entre ssh/rdp/vnc
- Tab desde selector → primer campo; Shift+Tab desde primer campo → selector

Campos visibles según tipo:
- SSH: Nombre, Host, Puerto, Usuario, Identity File, Descripción, Tags
- RDP: Nombre, Host, Puerto, Usuario, Dominio, Descripción, Tags
- VNC: Nombre, Host, Puerto, Usuario, Descripción, Tags

Puerto: placeholder cambia con tipo (22 / 3389 / 5900). Default en trySave también varía.

---

## List Changes (`model/list.go`)

`formatRow`: badge de tipo al inicio de cada fila: `[SSH]` `[RDP]` `[VNC]`

---

## Detail Changes (`model/detail.go`)

- Mostrar `Type` en header (junto al nombre)
- Mostrar `Domain` solo si RDP
- Tecla `c`: dispatch según `conn.Type` → `ssh.Connect`, `rdp.Connect`, o `vnc.Connect`

---

## App Changes (`model/app.go`)

Manejar `rdp.MsgRDPLaunched` y `vnc.MsgVNCLaunched`:
- Error → `statusMsg` rojo 3s
- Éxito → `statusMsg` verde 3s (`"RDP abierto"` / `"VNC abierto"`)

Para el mensaje de éxito usar `styles.MutedText` en lugar de `styles.ErrText`.

---

## Clients requeridos

| Protocolo | Cliente | Paquete Debian |
|-----------|---------|----------------|
| RDP | `xfreerdp` | `freerdp2-x11` |
| VNC | `vncviewer` | `tigervnc-viewer` |

Error claro si el cliente no está instalado (`exec.LookPath` antes de `Start`).
