## 1. UX Quick Wins

### 1.1 `c` y `e` desde la lista

`ListModel.handleKey` agrega dos casos cuando hay una conexión seleccionada:

- `e` → push `FormModel` con la conexión seleccionada (igual que entrar al detalle y presionar `e`)
- `c` → llama `store.RecordConnect(id)`, despacha `connectCmd(conn)` directo (mismo helper que `DetailModel`)

Precondición: `len(conns) > 0 && m.cursor < len(conns)`.

### 1.2 `n` cancela borrado explícitamente

En `DetailModel.handleConfirm`, `n` se maneja como caso explícito:

```
case "s", "y": → borrar y pop
case "n":       → cancelar (m.confirming = false)
default:        → ignorar (no cancela)
```

El footer ya muestra `(s/n)` — ahora es semánticamente correcto: solo `s`/`y` confirma, solo `n` cancela, otras teclas se ignoran.

### 1.3 Timeout de launch

Constante `launchTimeout = 2 * time.Second` en `internal/rdp/connect.go` y `internal/vnc/connect.go`, reemplaza el literal `time.Second` actual.

## 2. Agrupado por Tags

### Regla de agrupado

- Primera tag de `Connection.Tags` determina el grupo
- Sin tags → grupo `"sin tag"`
- Grupos ordenados alfabéticamente; `"sin tag"` siempre último
- Dentro de cada grupo: orden alfabético por `Name`
- Filtro activo → vista plana (sin headers de grupo)

### Estructura de datos interna

```go
type connGroup struct {
    label string
    conns []store.Connection
}
```

Función `groupConnections(conns []store.Connection) []connGroup` en `list.go`.

El cursor `m.cursor` sigue siendo índice sobre el slice plano de conexiones (`store.Filter` result), no sobre líneas visuales. La navegación `↑/↓` no cambia.

### Render

```
[work]
  > servidor-prod    [SSH]  root@192.168.1.10    hace 2h
    bastion          [SSH]  admin@10.0.0.1       nunca

[personal]
    nas              [SSH]  felipe@nas.local      ayer

[sin tag]
    windows-rdp      [RDP]  Administrador@...     nunca
```

Headers de grupo con `styles.MutedText` + corchetes. Línea en blanco entre grupos.

Cursor global: para determinar si la fila `i` (en el slice plano) es la seleccionada, se usa el índice acumulado al iterar los grupos.

## 3. Historial de Conexión

### Store

Campo nuevo en `Connection`:

```go
LastConnectedAt *time.Time `json:"last_connected_at,omitempty"`
```

Método nuevo:

```go
func (s *Store) RecordConnect(id string) error
```

Busca por ID, setea `LastConnectedAt = &now`, llama `save()`. Silencia el error si el ID no existe (conexión borrada entre tecla y dispatch).

### Cuándo se registra

Cuando el usuario presiona `c` en lista o detalle, antes de despachar el comando de conexión. No se espera resultado exitoso.

### Formato `timeAgo`

Función `timeAgo(t *time.Time) string` en `list.go`:

| Condición | Output |
|-----------|--------|
| `nil` | `"nunca"` |
| `< 60s` | `"ahora"` |
| `< 1h` | `"hace Xm"` |
| `< 24h` | `"hace Xh"` |
| `< 7d` | `"hace Xd"` |
| resto | `"DD/MM/YY"` |

Se muestra al final de cada fila en `styles.MutedText`, right-aligned con `fmt.Sprintf`.

## 4. Export / Import JSON

### Store

```go
func (s *Store) ExportAll(path string) error
// Serializa s.Connections al path en formato {connections: [...]}

func (s *Store) ImportMerge(path string) (int, error)
// Carga el archivo, agrega solo IDs no existentes, retorna cantidad agregada, llama save()
```

### TUI — modo inline en `ListModel`

`ListModel` gana:

```go
type inputMode int
const (
    inputNone inputMode = iota
    inputExport
    inputImport
)

pathInput textinput.Model
mode      inputMode
```

**Activación:**
- `X` en lista normal → `m.mode = inputExport`, `m.pathInput.Focus()`
- `I` en lista normal → `m.mode = inputImport`, `m.pathInput.Focus()`

**Durante modo input:** el footer muestra el prompt con el input activo. Las teclas de navegación van al input, no a la lista. `Esc` cancela, `Enter` ejecuta.

**Ejecución:**

Export → `store.ExportAll(path)` → retorna `MsgExportDone{Path, Count, Err}`  
Import → `store.ImportMerge(path)` → retorna `MsgImportDone{Added, Err}`

Estos mensajes los maneja `AppModel` como el resto de mensajes de operación, mostrando en status bar 3 segundos:

- `✓ Exportado: N conexiones → path`
- `✓ Importado: N nuevas conexiones`
- `! Error: <mensaje>`

### Footer actualizado

```
[n]ueva  [/]filtrar  [e]editar  [c]conectar  [X]exportar  [I]importar  [q]salir
```

(Se muestra solo cuando hay conexiones seleccionadas para `e` y `c`.)
