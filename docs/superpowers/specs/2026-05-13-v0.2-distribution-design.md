# julssh v0.2 — Distribution Design Spec

**Date:** 2026-05-13
**Status:** Approved

## Overview

Configurar pipeline de distribución automática via GoReleaser + GitHub Actions. Al crear un tag `v*.*.*`, se compilan binarios para Linux amd64/arm64, se genera un `.deb` para amd64, y se publica un GitHub Release con todos los assets.

---

## Archivos nuevos

```
julssh/
├── .goreleaser.yml
└── .github/
    └── workflows/
        └── release.yml
```

---

## Flujo

```
git tag v0.2.0 && git push --tags
        │
        ▼
GitHub Actions (release.yml)
        │  checkout (fetch-depth: 0)
        │  setup-go (versión de go.mod)
        │  goreleaser release --clean
        ▼
GoReleaser (.goreleaser.yml)
        ├── go test ./...
        ├── go build linux/amd64  → julssh_linux_amd64.tar.gz
        ├── go build linux/arm64  → julssh_linux_arm64.tar.gz
        ├── nfpm deb amd64        → julssh_amd64.deb
        ├── checksums.txt
        └── GitHub Release v0.2.0 con todos los assets
```

**Trigger:** tags con formato `v*.*.*` únicamente.

## .goreleaser.yml

```yaml
version: 2

before:
  hooks:
    - go mod tidy
    - go test ./...

builds:
  - env: [CGO_ENABLED=0]
    goos: [linux]
    goarchs: [amd64, arm64]
    ldflags: -s -w -X main.version={{.Version}}

archives:
  - formats: [tar.gz]
    name_template: "{{ .ProjectName }}_{{ .Os }}_{{ .Arch }}"

nfpms:
  - package_name: julssh
    homepage: https://github.com/felipendelicia/julssh
    description: Gestor TUI de conexiones SSH. Dedicado a mi hermana Julieta.
    maintainer: Felipe Ndelicia
    license: MIT
    formats: [deb]
    bindir: /usr/local/bin
    contents:
      - src: README.md
        dst: /usr/share/doc/julssh/README.md

checksum:
  name_template: checksums.txt

release:
  github:
    owner: felipendelicia
    name: julssh
  name_template: "v{{ .Version }}"

changelog:
  sort: asc
  filters:
    exclude: ['^docs:', '^chore:']
```

## .github/workflows/release.yml

```yaml
name: Release

on:
  push:
    tags:
      - 'v*.*.*'

permissions:
  contents: write

jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: actions/setup-go@v5
        with:
          go-version-file: go.mod

      - uses: goreleaser/goreleaser-action@v6
        with:
          version: latest
          args: release --clean
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## install.sh — modo descarga

Agregar flag `--download` que baja el binario del último GitHub Release sin necesitar Go:

```bash
bash install.sh --download        # descarga binario pre-compilado
bash install.sh                   # compila desde fuente (comportamiento actual)
```

Detecta arquitectura automáticamente (`uname -m` → amd64 o arm64), descarga el `.tar.gz` correspondiente del último release via GitHub API, extrae y copia a `~/.local/bin/`.

## README — sección instalación actualizada

Después del release, la instalación primaria pasa a ser:

```bash
# Sin Go instalado (descarga binario)
bash <(curl -fsSL https://raw.githubusercontent.com/felipendelicia/julssh/main/install.sh) --download

# Con Go instalado (compila desde fuente)
git clone https://github.com/felipendelicia/julssh.git
cd julssh && bash install.sh
```

## main.go — flag --version

Agregar variable `version` inyectada por GoReleaser y flag `--version`:

```go
var version = "dev"

func main() {
    if len(os.Args) > 1 && os.Args[1] == "--version" {
        fmt.Println("julssh", version)
        os.Exit(0)
    }
    // ... resto del main
}
```

`julssh --version` imprime `julssh v0.2.0`.
